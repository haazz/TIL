# 멱등성 (Idempotency)이란

- 같은 요청을 여러 번 보내도 **서버의 상태 결과가 동일**하게 유지되는 성질이다.
- 주의: "응답 바디가 매번 똑같다"는 뜻이 아니라, "여러 번 호출해도 부수효과(상태 변화)가 한 번 호출한 것과 같다"는 뜻이다.

# HTTP 메서드별 멱등성

- **멱등함** : GET, PUT, DELETE, HEAD
  - GET : 조회만 하므로 상태 변화 없음.
  - PUT : 같은 값으로 여러 번 덮어써도 결과 동일.
  - DELETE : 여러 번 삭제해도 "삭제됨" 상태로 동일. (응답 코드는 다를 수 있음)
- **멱등하지 않음** : POST
  - 호출할 때마다 새 리소스가 생성되어 상태가 계속 바뀐다.

# 왜 중요한가

- 네트워크 오류로 요청을 재시도할 때, 멱등하지 않은 작업은 중복 처리(중복 결제 등)를 일으킬 수 있다.
- 비멱등 작업은 **멱등성 키(idempotency key)**를 두어, 같은 키의 요청은 서버가 한 번만 처리하도록 설계한다.
