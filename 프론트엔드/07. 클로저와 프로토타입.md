# 클로저 (Closure)

- 함수가 **선언될 당시의 렉시컬 스코프(변수 환경)를 기억**하여, 외부 함수가 종료된 뒤에도 그 변수에 접근하는 것이다.

```js
function counter() {
  let count = 0;
  return function () {
    count += 1;
    return count;
  };
}
const next = counter();
next(); // 1
next(); // 2  (count가 계속 유지됨)
```

# 클로저의 용도

- **상태 은닉** : 외부에서 직접 못 건드리는 private 변수처럼 쓴다.
- **상태 유지** : 위 카운터처럼 호출 간 값을 유지한다.

# 클로저의 메모리 주의점

- 클로저가 변수를 참조하는 동안 그 변수는 GC(가비지 컬렉션) 대상이 되지 않는다.
- 불필요한 클로저나 이벤트 리스너가 쌓이면 메모리 누수로 이어질 수 있다.

# 프로토타입 (Prototype)

- 자바스크립트는 **프로토타입 기반 상속**을 사용한다.
- 모든 객체는 내부에 `[[Prototype]]` 링크를 가지며, 프로퍼티를 찾을 때 자기 객체에 없으면 **프로토타입 체인**을 따라 위로 탐색한다.

```js
const arr = [1, 2, 3];
arr.push(4); // arr 자체엔 push가 없지만, Array.prototype에서 찾아 사용
```

# 프로토타입 체인

- 객체 → 그 객체의 prototype → 상위 prototype → ... → `Object.prototype` → `null` 순으로 탐색한다.
- `class` 문법도 내부적으로는 이 프로토타입 메커니즘 위에서 동작하는 문법 설탕이다.
