# 타입 좁히기 (Type Narrowing)

- 유니온 타입 등 넓은 타입을, 특정 조건으로 더 구체적인 타입으로 줄이는 것이다.
- 좁혀진 블록 안에서는 TS가 그 타입의 프로퍼티/메서드를 안전하게 허용한다.

# 좁히기 수단

- `typeof` : 원시 타입 구분에 쓴다. 예: `typeof x === "string"`.
- `instanceof` : 클래스 인스턴스 구분에 쓴다. 예: `x instanceof Date`.
- `in` 연산자 : 프로퍼티 존재 여부로 구분한다. 예: `"bark" in animal`.
- 진위 검사 : `if (value)`로 null/undefined를 걸러낸다.

# 사용자 정의 타입 가드

- `매개변수 is 타입` 형태의 반환 타입으로 직접 타입 가드를 만든다.

```ts
function isCat(animal: Cat | Dog): animal is Cat {
  return (animal as Cat).meow !== undefined;
}
if (isCat(animal)) {
  animal.meow(); // Cat으로 좁혀짐
}
```

# 판별 유니온 (Discriminated Union)

- 공통 판별 필드(예: `kind`)를 둔 유니온을, 그 필드로 분기해 좁히는 패턴이다.

```ts
type Shape =
  | { kind: "circle"; radius: number }
  | { kind: "square"; size: number };

function area(s: Shape) {
  switch (s.kind) {
    case "circle": return Math.PI * s.radius ** 2;
    case "square": return s.size ** 2;
  }
}
```
