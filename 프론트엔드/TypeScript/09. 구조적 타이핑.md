# 구조적 타이핑 (Structural Typing)

- 타입의 이름이 아니라 **구조(모양)**가 같으면 호환되는 타입으로 보는 방식이다.
- TypeScript는 구조적 타이핑을 채택한다.
- "오리처럼 생기고 오리처럼 울면 오리"라는 덕 타이핑(duck typing)과 같은 개념이다.

```ts
interface Point {
  x: number;
  y: number;
}

function printPoint(p: Point) {
  console.log(p.x, p.y);
}

const obj = { x: 1, y: 2, z: 3 };
printPoint(obj); // OK: Point의 모양(x, y)을 만족하므로 통과
```

# 명목적 타이핑 (Nominal Typing)

- 선언된 타입의 **이름이나 상속 관계**가 같아야 호환되는 방식이다.
- Java, C# 등이 명목적 타이핑을 쓴다.
- 모양이 같아도 타입 이름이 다르면 호환되지 않는다.

# 비교 정리

- 구조적 타이핑(TS) : 모양이 같으면 OK. 유연하다.
- 명목적 타이핑(Java) : 이름/선언이 같아야 OK. 엄격하다.
- TS에서 명목적 타이핑이 필요하면, 브랜딩(branding) 기법으로 흉내 낼 수 있다.
