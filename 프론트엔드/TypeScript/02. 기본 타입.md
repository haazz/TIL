# 원시 타입

- `string`, `number`, `boolean`, `null`, `undefined`, `symbol`, `bigint`가 있다.
- 변수 선언 시 `const name: string = "haji"` 처럼 타입을 명시한다.
- 명시하지 않아도 초기값으로 타입을 추론(inference)한다. 추론이 가능하면 굳이 명시하지 않는 것이 관례이다.

# 배열과 튜플

- 배열은 `number[]` 또는 `Array<number>`로 표기한다.
- 튜플(tuple)은 길이와 각 위치의 타입이 고정된 배열이다. 예: `[string, number]`.

# 객체 타입

- `{ name: string; age: number }` 처럼 프로퍼티별 타입을 지정한다.
- `?`를 붙이면 선택적(optional) 프로퍼티가 된다. 예: `age?: number`.
- `readonly`를 붙이면 재할당이 불가능한 프로퍼티가 된다.

# 함수 타입

- 매개변수와 반환값에 타입을 지정한다. 예: `function add(a: number, b: number): number`.
- 반환값이 없으면 `void`를 쓴다.

# 특수 타입

- `any` : 타입 검사를 포기한다. (사용 지양)
- `unknown` : 모든 값을 담지만 사용 전 타입 좁히기를 강제하는 안전한 any이다.
- `never` : 값이 존재할 수 없는 타입이다. (throw, 무한루프 등)
- `void` : 반환값이 없음을 나타낸다.

# 리터럴 타입

- 특정 값 자체를 타입으로 쓸 수 있다. 예: `type Direction = "up" | "down"`.
- 유니온과 함께 쓰면 허용 값을 좁게 제한할 수 있다.
