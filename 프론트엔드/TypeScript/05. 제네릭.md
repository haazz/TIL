# 제네릭이란

- 타입을 파라미터처럼 받아서, 재사용 가능한 타입 안전 컴포넌트를 만드는 기능이다.
- 호출하는 쪽에서 타입을 주입하므로, 여러 타입에 대해 같은 로직을 타입 안전하게 재사용할 수 있다.

```ts
function identity<T>(value: T): T {
  return value;
}
identity<string>("hi"); // T = string
identity(42);            // T = number (추론됨)
```

# 실무 활용 예시

- API 요청/응답에서 다양한 DTO 타입을 하나의 함수로 관리할 때 쓴다.

```ts
function apiRequest<T>(url: string): Promise<T> {
  return fetch(url).then((res) => res.json());
}
const user = await apiRequest<User>("/users/1"); // 반환 타입이 User로 고정됨
```

# 제약 조건 (extends)

- 제네릭 타입에 조건을 걸어 특정 프로퍼티가 있는 타입만 받게 할 수 있다.

```ts
function getLength<T extends { length: number }>(x: T): number {
  return x.length; // length가 있는 타입만 허용
}
```

# 정리

- "타입을 파라미터화해 재사용한다"가 한 줄 핵심이다.
- 컬렉션, API 래퍼, 유틸 함수 등에서 자주 쓰인다.
