# any

- 타입 검사를 포기하는 타입이다. 어떤 값도 할당 가능하고 어떤 연산도 허용한다.
- 사실상 JavaScript처럼 동작하므로 TS의 장점을 잃는다. 사용을 지양해야 한다.

# unknown

- 모든 값을 담을 수 있다는 점은 any와 같다.
- 하지만 사용하기 전에 반드시 타입 좁히기(narrowing)를 강제한다. 그래서 "안전한 any"라고 부른다.

```ts
let value: unknown = getData();
// value.toUpperCase();        // 에러: 타입을 모름
if (typeof value === "string") {
  value.toUpperCase();         // OK: string으로 좁혀짐
}
```

# never

- 값이 존재할 수 없는 타입이다.
- 함수가 정상적으로 끝나지 않을 때(예외 throw, 무한루프)의 반환 타입이다.
- 도달 불가능한 분기(exhaustive check)에서 누락을 컴파일 타임에 잡는 데 활용한다.

```ts
function fail(msg: string): never {
  throw new Error(msg);
}
```

# 자주 하는 오해

- "unknown = 나중에 타입 명시, never = 이후에도 명시 안 함"은 틀린 설명이다.
- 핵심 구분은 "시점"이 아니라 **안전성과 도달 가능성**이다.
  - any: 검사 포기 (위험)
  - unknown: 담되 쓰기 전 검증 강제 (안전)
  - never: 존재할 수 없는 값
