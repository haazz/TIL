# union 타입

- 여러 리터럴을 `|`로 묶어 허용 값을 제한하는 타입이다. 예: `type Dir = "up" | "down"`.
- 런타임 코드를 생성하지 않아 가볍다. 가장 권장되는 방식이다.

# enum

- 이름 있는 상수 집합을 정의한다.

```ts
enum Color { Red, Green, Blue }
```

- 단점: 컴파일 후 런타임 객체를 생성하므로 번들 크기가 늘고, 숫자 enum은 역매핑 등 부수효과가 있다.
- 그래서 실무에서는 union 타입으로 대체하는 경우가 많다.

# const assertion (as const)

- 값을 좁은 리터럴 타입으로 고정한다.

```ts
const DIRECTIONS = ["up", "down"] as const;
// 타입: readonly ["up", "down"]
type Direction = typeof DIRECTIONS[number]; // "up" | "down"
```

- 배열/객체를 불변(readonly)으로 만들고, 거기서 union 타입을 뽑아낼 때 유용하다.

# 선택 기준

- 단순 값 제한은 **union 타입**을 우선한다. (가볍고 안전)
- 상수 묶음에서 union을 추출하고 싶으면 **union + as const** 조합을 쓴다.
- enum은 런타임 객체가 꼭 필요한 경우에만 제한적으로 쓴다.
