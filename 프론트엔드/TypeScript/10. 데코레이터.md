# 데코레이터란

- 클래스, 메서드, 프로퍼티, 매개변수에 메타데이터나 부가 동작을 주입하는 함수이다.
- 선언부 위에 `@이름` 형태로 붙인다.
- Java/Spring의 어노테이션(annotation)과 같은 개념이다.

# 종류

- 클래스 데코레이터 : 클래스 정의 자체에 적용한다.
- 메서드 데코레이터 : 메서드에 적용한다. (로깅, 권한 체크 등)
- 프로퍼티 데코레이터 : 클래스 필드에 적용한다.
- 매개변수 데코레이터 : 매개변수에 적용한다. (의존성 주입 등)

# NestJS 예시

- 백엔드 프레임워크 NestJS가 데코레이터를 적극 사용한다.

```ts
@Controller("users")
export class UserController {
  constructor(private readonly userService: UserService) {}

  @Get(":id")
  findOne(@Param("id") id: string) {
    return this.userService.findOne(id);
  }
}
```

- `@Controller`, `@Get`, `@Param`, `@Injectable` 등이 데코레이터이며, Spring의 `@RestController`, `@GetMapping`과 대응된다.

# 참고

- 데코레이터는 별도 설정(`experimentalDecorators` 또는 TS 5.0+ 표준 데코레이터)이 필요할 수 있다.
- 동작 원리는 "선언 대상을 감싸 부가 기능을 더하는 고차 함수"로 이해하면 된다.
