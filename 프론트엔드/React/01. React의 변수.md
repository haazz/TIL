# state

- state는 컴포넌트의 상태를 나타내는 객체이다.
- 내부에서 관리한다.
- state는 변경될 수 있으며, setState() 메서드를 사용하여 상태를 업데이트할 수 있다.
- state는 복잡성을 높이고 예측가능성을 낮추므로 state를 너무 많이 쓰지 않을 것을 권장하기도 한다.

# Ref

- 컴포넌트의 DOM 요소나 React 엘리먼트에 접근하기 위해 사용한다.
- useRef()에서 만들어지는 ref 객체는 DOM ref만을 위한 것이 아니다. ref 객체는 변경할 수 있고 어떤 값이든 보유할 수 있는 프로퍼티를 가진 일반 컨테이너이다.
- 값이 변경되도 리렌더링 되지 않는다.

# props

- 부모 컴포넌트에서 자식 컴포넌트로 전달하는 데이터
- props는 읽기 전용이며, 자식 컴포넌트에서 직접 수정할 수 없는 불변 값이다.
