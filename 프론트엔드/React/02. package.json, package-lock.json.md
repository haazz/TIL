# package.josn
일반적으로 프로젝트의 이름, 버전, 설명 등과 서드파트 패키지인 의존성 목록이 포함된다.

'npm install' or 'yarn install'을 통해 의존성을 자동으로 설치할 수 있다.

# package-lock.json
의존성 트리에 대한 정보를 갖고 있는 파일이다.
package.json 파일 안에 **version range**가 조재한다. 이는 특정 버전을 지칭하는 것이 아니라 range를 말한다. (^1.0.0, ~1.0.0 등)
이러한 range로 인해 협업 혹은 다른 환경에서 문제가 발생할 수 있기 때문에 의존성 트리를 포함한 정확한 버전, 버전 충돌 등의 정보가 포함되어 있는 package-lock.json 파일이 필요하다.
