# 자바스크립트는 싱글 스레드

- JS 엔진은 하나의 콜스택을 가진 싱글 스레드로 동작한다.
- 그럼에도 비동기 처리가 가능한 이유는 런타임(브라우저/Node.js)이 제공하는 이벤트 루프와 큐 덕분이다.

# 이벤트 루프 (Event Loop)

- 콜스택이 비면, 큐에 대기 중인 콜백을 꺼내 콜스택에 올려 실행하는 반복 구조이다.
- 비동기 작업(타이머, I/O 등)은 백그라운드에 맡기고, 완료되면 그 콜백이 큐로 들어온다.
- 덕분에 메인 스레드를 막지 않고 동시성을 흉내 낸다.

# 마이크로태스크 vs 매크로태스크

- **마이크로태스크 큐** : `Promise.then`, `queueMicrotask` 등. 우선순위가 높다.
- **매크로태스크 큐** : `setTimeout`, `setInterval`, I/O 콜백 등.
- 실행 규칙: 매크로태스크 하나를 처리한 뒤, **마이크로태스크 큐를 전부 비우고** 다음 매크로태스크로 넘어간다.
- 그래서 `setTimeout(fn, 0)`보다 `Promise.then(fn)`이 먼저 실행된다.

# 콜백 → Promise → async/await

- **콜백** : 완료 시 호출할 함수를 넘기는 방식. 중첩되면 콜백 지옥이 된다.
- **Promise** : 미래의 값을 담는 객체. pending → fulfilled/rejected. `.then` 체이닝으로 평탄화한다.
- **async/await** : Promise를 동기 코드처럼 읽히게 하는 문법 설탕. 내부는 여전히 Promise이다.

# Promise 정적 메서드

- `Promise.all` : 전부 성공해야 resolve, 하나라도 실패하면 즉시 reject.
- `Promise.allSettled` : 성공/실패 무관하게 전부 끝날 때까지 기다린다.
- `Promise.race` : 가장 먼저 끝난 것(성공·실패 무관)을 채택.
- `Promise.any` : 가장 먼저 성공한 것을 채택.

# 비동기 에러 핸들링

- `async/await`는 `try/catch`로, Promise 체인은 `.catch()`로 처리한다.
- `await`을 빠뜨리거나 처리하지 않은 reject는 `unhandledRejection`이 된다.
