# 스프링부트 소개

스프링 ≠ 스프링부트

스프링부트는 모든 요구사항을 수용할 수 있는 너무 유연한 스프링에 대해 강한 주장을 갖고 빠르게 만들 수 있게 도와주는 도구이다

그만큼 스프링부트에서 사용하는 기술들이 실제로 스프링에서 어떻게 동작하고 있는지 파악하기 어렵고 추가적인 이해가 필요해 보인다

예를들어 데이터베이스 커넥션풀 설정이 없이 스프링부트의 properties를 사용하여 커넥션풀을 내부에서 생성해준다

# 스프링부트 핵심 원칙

- XML 사용 x
- 강한주장을 기반으로 한 스프링 애플리케이션을 만든다
- 빠른 개발과 배포를 위한 환경을 제공한다
- Stand Alone 한 애플리케이션을 만들기 위해 내부에서 서버, 보안, 매트릭 등의 비기능적인 기술을 제공한다
