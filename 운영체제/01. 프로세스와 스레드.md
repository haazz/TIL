# 프로세스 (Process)

- 실행 중인 프로그램으로, **독립된 메모리 공간을 할당받은 실행 단위**이다.
- 각 프로세스는 자신만의 Code, Data, Heap, Stack 영역을 가진다.
- 프로세스 간에는 메모리를 공유하지 않으므로, 통신하려면 별도의 IPC(Inter-Process Communication)가 필요하다.

# 스레드 (Thread)

- 프로세스 내에서 실제로 실행되는 흐름의 단위이다.
- 한 프로세스의 스레드들은 **Code, Data, Heap 영역을 공유**하고, **Stack과 레지스터는 각자** 가진다.
- 메모리를 공유하므로 스레드 간 통신·전환 비용이 프로세스보다 가볍다.

# 자주 하는 오해

- "프로세스 = CPU 코어 단위"는 부정확하다. 프로세스는 독립 메모리를 가진 실행 단위이다.
- "스레드는 제한 없이 늘릴 수 있다"도 틀리다. 각 스레드가 스택 메모리를 쓰고 OS 자원 한계가 있어 개수에 제약이 있다.

# 비교 정리

- 프로세스 : 독립 메모리, 안정적(하나가 죽어도 격리), 전환 비용 큼, IPC 필요.
- 스레드 : 메모리 공유, 가볍고 빠름, 단 한 스레드의 오류가 프로세스 전체에 영향.

# 멀티스레드 주의점

- 메모리를 공유하므로 여러 스레드가 같은 데이터를 동시에 바꾸면 **경쟁 상태(Race Condition)**가 발생한다.
- 이를 막기 위해 동기화(Lock, synchronized, Atomic 등)가 필요하다.
